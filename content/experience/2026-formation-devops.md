Parcours d'apprentissage intensif sur les technologies DevOps, structuré en plusieurs phases :

- **Phase 1** — Fondations : Linux, réseaux, scripting Bash & Python, Git
- **Phase 2** — Conteneurisation : Docker, CI/CD
- **Phase 3** — Cloud & IaC : AWS, Terraform, Ansible
- **Phase 4** — Orchestration : Kubernetes
- **Phase 5** — Observabilité & SRE

Chaque phase est validée par un **projet concret** versionné sur GitHub avec workflow Git professionnel.
