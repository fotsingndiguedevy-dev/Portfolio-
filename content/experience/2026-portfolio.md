Construction d'un portfolio moderne en **Next.js 15 + TypeScript + Tailwind CSS**, avec un design "terminal hacker" cohérent.

**Points techniques :**

- Intégration de l'API GitHub pour afficher mes repos automatiquement
- Route API sécurisée côté serveur (token jamais exposé)
- Cache intelligent (revalidation toutes les heures)
- Workflow Git professionnel (branches `main` / `develop`, commits conventionnels)
- Bilingue FR/EN en cours
- Déploiement automatique sur Vercel à chaque push

**Objectif :** démontrer mes compétences DevOps à travers un projet réel et maintenu.
